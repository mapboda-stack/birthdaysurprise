# 💜 Happy Birthday, My Joy

A romantic and interactive birthday website created with love for someone truly special.

This project is more than just a website. It is a digital birthday gift designed to celebrate Shalom, express appreciation, share beautiful memories, and speak prayers and encouragement over her life as she begins a new chapter.

## ✨ Features

- **Cinematic Birthday Hero:** A beautiful introduction with a romantic dark-purple theme.
- **Birthday Countdown:** A live countdown to November 4, 2026, which changes to a birthday celebration message on the special day.
- **Appreciation Section:** Thoughtful messages celebrating her heart, personality, dreams, growth, and peace.
- **Memories Gallery:** A collection of personal photographs and meaningful moments.
- **Personal Love Letter:** A heartfelt message expressing love, gratitude, encouragement, and hopes for the future.
- **Birthday Prayer:** A Christian prayer with Bible verses from Numbers 6:24–25, Jeremiah 29:11, and Proverbs 3:5.
- **Interactive Surprise:** A button that reveals a special message with floating hearts.
- **Background Music Player:** A play/pause music control for a more personal experience.
- **Responsive Design:** Optimized for mobile phones, tablets, and desktop screens.
- **Smooth Navigation:** Easy navigation between the different sections of the website.
- **Map_Technologies Footer:** A link to the developer's portfolio.

## 🛠️ Technologies Used

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Add the required photographs to the `images` folder.
4. Add the background music file to the `music` folder.
5. Open `index.html` in a browser to explore the website.

The image and music filenames must match the paths used in the HTML file.
